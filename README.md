## Descripción

Esta es la entrega de la Tarea 1 del curso CC5002 - Desarrollo Web. El objetivo es construir un prototipo de aplicación web para gestionar actividades recreativas. La aplicación permite:

- Visualizar una portada con las últimas 5 actividades.
- Agregar nuevas actividades a través de un formulario validado con JavaScript (No se puede todavia)
- Ver un listado completo de actividades.
- Ver estadísticas representadas mediante gráficos.

---

## 📌 Notas de Implementación

- Todas las validaciones del formulario se realizan con JavaScript, sin usar `required`.
- Para las estadísticas se utilizó la librería [Chart.js](https://www.chartjs.org/) desde CDN.
- En index.html usé un grid en vez de un table como en listado.html, eso fue yo probando la diferencia.
- Para el estilo me contenté con colores blancos, negros y grises, uso de flexbox, estructurado verticalmente.
- Alcance a hacer el listado, tanto el html como el css, pero no lo que sería 'informacion_actividad' que seria la pagina la cual muestra la informacion de la fila al hacerle click.
